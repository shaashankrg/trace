title: How to Return an Item
published_at: 2026-09-01
---
To start a return, open your order in your Kestrel account and choose "Return item". We email you a free prepaid return label. Return shipping is free for all returns within the return window.

Pack the item securely, attach the label, and drop it off with the carrier. You can also return items in person at any of our {{store_count}} Kestrel stores and skip shipping entirely.
