title: How to Return an Item
published_at: 2025-02-01
---
To return an item, email help@kestrel.example with your order number. We send a return label by email. The cost of the return label, $7.95, is deducted from your refund.

Pack the item securely and drop it off with the carrier. You can also return items in person at any Kestrel store.
